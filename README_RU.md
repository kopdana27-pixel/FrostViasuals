# FROST VISUALS 3.0 — проект сайта и Fabric

## Состав
- `web/` — адаптивный сайт в фирменной фиолетово-чёрной теме, каталог модулей, поиск, профили JSON, интерфейсы ролей и панели.
- `api/` — Express API с Supabase Auth, проверкой ролей на сервере и чтением конфигурации для мода.
- `supabase/schema.sql` — таблицы и RLS.
- `mod/1.21.4` и `mod/1.21.11` — отдельные Fabric-проекты.
- `netlify.toml` — публикация статики из `web/`; API размещается отдельно.

## Важно о текущей готовности
Сайт сейчас работает как локальный визуальный прототип: переключатели и профили хранятся в браузере. Экран ролей/админки — демонстрация интерфейса, а не настоящая авторизация. Для реальных аккаунтов и защищённых ролей нужно подключить Supabase: выполнить SQL, подключить Supabase Auth в веб-клиенте и развернуть API с переменными окружения. API уже проверяет токен Supabase и роль в БД; не публикуйте service_role key.

Fabric-проекты являются стартовыми каркасами, а не готовыми собранными JAR. Сначала нужно собрать и протестировать каждую версию отдельно на ПК с Java 21. 1.21.11 использует официальные Mojang mappings; 1.21.4 — Yarn.

## Локальный запуск сайта
Можно открыть `web/index.html` напрямую. Для API: `cd api`, `npm install`, заполнить `.env` по `.env.example`, `npm start`.

## Публикация Netlify
1. В Termux скопировать проект в приватную папку, не запускать npm в `storage/downloads`.
2. Установить Netlify CLI: `npm install -g netlify-cli`.
3. Перейти в корень проекта и выполнить `npx netlify login`, затем `npx netlify deploy --prod --dir web`.
4. В `netlify.toml` заменить `YOUR-API-DOMAIN` на адрес опубликованного API. Сам Netlify-хостинг статических файлов не запускает постоянно Node API.

## Безопасность
- Никогда не помещайте Supabase `service_role` key в браузер или мод.
- Не выдавайте Owner через localStorage. Owner назначается вручную в Supabase после создания аккаунта.
- Проверяйте права на API и в RLS.
- Не обещайте автоматический прирост FPS/снижение ping: мод может уменьшать отдельные визуальные нагрузки, но не менять качество сети/серверный latency.
