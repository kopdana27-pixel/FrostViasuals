# Fabric-моды Frost Visuals 3.0

Два отдельных проекта: `1.21.4` и `1.21.11`. Для сборки нужен ПК с Java 21 и Gradle wrapper/установленным Gradle.

**Статус:** это стартовые независимые Fabric-проекты, не готовые игровые клиенты. Сборку и запуск нужно проверить на соответствующих версиях Minecraft и Fabric Loader. Мод 1.21.11 пока содержит только точку входа; визуальные модули будут переноситься отдельными этапами. 1.21.11 использует официальные Mojang mappings, а 1.21.4 — Yarn. Fabric указывает, что 1.21.11 — последняя обфусцированная версия, а для следующих версий нужна другая схема mappings. См. https://docs.fabricmc.net/develop/porting/mappings/ и https://fabricmc.net/2025/12/05/12111.html.

Не переносите чужой код/ресурсы из Bee Visuals. Используйте только идеи функций и создавайте собственную реализацию.
